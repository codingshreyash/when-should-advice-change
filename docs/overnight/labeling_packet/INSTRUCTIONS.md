# Labelling instructions

Thank you for helping. This packet holds two blank sheets:

- `career_pilot_sheet.csv` (70 rows)
- `career_v2_sheet.csv` (140 rows)

Each row describes a person facing a career decision and asks what they should do. Open the
sheets in any spreadsheet program and save them as CSV when you finish.

## Before you start

- Please label only if you did not write these scenarios.
- Work only from this packet. Do not open the project repository, any other file from the
  project, or any AI model's answers to these situations, before or while you label.
- Work alone. Do not discuss rows with the other labeller until you have both handed in your
  sheets.

## For each row

1. Read the `prompt` and the `question`.
2. In `your_label`, type exactly one option code, copied from the `options` column. The code
   is the word before `=`, for example `accept`. Use no other text.
3. Choose `need_more_information` only if a fact you would need in order to decide is
   actually missing. Do not choose it just because the decision is hard.
4. In `why`, write one sentence: the fact or priority that drives your choice.
5. Many rows describe the same situation with small differences. Judge each row on its own
   text. Do not try to make your answers consistent across rows.

Fill in every row. Do not add, remove, rename or reorder columns, and do not change the
`row_id` values.
